# 窗口收纳工具

Windows 窗口分组收纳工具。将多个程序或游戏窗口加入分组后，点击小卡片或分组名可按原有尺寸显示整组窗口；切换到其他程序后自动收纳。

## 下载与运行

下载仓库中的 [`窗口收纳工具.exe`](窗口收纳工具.exe)，双击运行。需要 Windows 以及 .NET Framework 4.0 或更高版本。关闭主窗口时，工具会留在系统托盘；可从托盘菜单选择“恢复全部并退出”。

## 使用方法

1. 点击“+ 收纳窗口”，选择要收纳的窗口并填写分组名。
2. 点击分组名或小卡片，显示该组全部窗口。
3. 切换到组外窗口后，该组自动收纳。
4. 对需要暂时保持显示的窗口，点击卡片上的“临时固定”；再次点击“取消固定”即可恢复自动收纳。
5. 点击“取消收纳”可将单个窗口移出工具。右键分组名可取消收纳整组。

小卡片显示收纳时保存的静态画面，画面不会持续刷新。工具通过隐藏和显示原窗口工作，不嵌入或缩小游戏窗口；部分游戏可能仍会对窗口显隐作出自己的处理。请先保存游戏进度，再对重要游戏窗口使用。

## 从源码构建

运行 `build.ps1`。脚本使用 Windows 自带的 .NET Framework C# 编译器，输出 `窗口收纳工具.exe`。
